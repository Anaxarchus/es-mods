# The Shoal: materials and exotic outfits.
#
# None of these are sold by any outfitter. The materials come from the belt,
# the wrecks and the guardians. Since v0.3 (DESIGN.md section 15) the
# exotic lines (thirteen since v0.3.4, when the Driftnet Ramscoop joined;
# fourteen since v0.3.5, the Lamprey Launcher) come only from drowned wrecks
# and salvage leads (Mk I, rarely Mk II); Mk III only by upgrading at the
# Breakers' Yard (the mod's code). The workshop
# (see "shoal workshop.txt") builds only the Warden Steward.
#
# Since v0.3 the workshop takes refined materials only (DESIGN.md section 14):
# 10 Shoal Glass refine into 1 Refined Shoal Glass (sale 40,000) and 3 Warden
# Cores into 1 Refined Warden Core (sale 180,000), so refining neither gains
# nor loses sale value.
#
# Sale values ("cost") of the exotics were set (v0.2) below what the old
# workshop recipes consumed to make them (Mk I: 150k + 3 refined glass = 270k; Mk II:
# 1.59M including the Mk I; Mk III: 5.79M including the Mk II), so crafting
# and selling never turns a profit:
#	Mk I 240,000 / Mk II 1,450,000 / Mk III 5,400,000 for every line.
# The exotic lines (six from v0.1, six from v0.2, one each from v0.3.4 and v0.3.5) all use those prices
# and the same recipes. The Warden Steward (crew) line has its own, cheaper
# recipe (Mk I: 2 refined glass + 1 refined core + 100k = 360k; Mk II: 1.16M
# including the Mk I; Mk III: 3.94M including the Mk II):
#	Mk I 300,000 / Mk II 1,000,000 / Mk III 3,500,000.

# =========================================================================
# Lamprey Launcher (Secondary Weapons, 20 space, gun port; v0.3.5)
# =========================================================================
# Fires Glass Lampreys: a bead of Shoal Glass spun around a charged filament,
# one Shoal Glass each (made at Breaker's Rest by the mod's code). Fast,
# "magnetic" homers that do very little shield or hull damage but drain
# energy dramatically, add moderate heat, and carry every status effect that
# takes a ship out of a fight: ion and energy damage to drain it, disruption
# and a little discharge to strip its shields, slowing to pin it, scrambling
# to jam its guns.
#
# Why a separate ammunition and not Shoal Glass itself (DESIGN.md section
# 21): the outfitter's automatic refill (OutfitterPanel::Refill) and a manual
# install (OutfitterPanel::ShipCanAdd) both ask Outfit::CanAdd, which floors
# every attribute without a minimum override at 0, "installable" included.
# Shoal Glass ("installable" -1) can therefore never be loaded, and any
# launcher attribute that let the refill load it ("installable" +N) would also
# let a captain install glass, Warden Cores, Deep Lattice or any stock
# mineral by hand, and would label the launcher "This is not an installable
# item." So the line fires its own ammunition, normal ammunition in every way
# ("glass lamprey capacity" like "sidewinder capacity"), and Shoal Glass stays
# a cargo material that sells at full value.
#
# How the status damage works (Weapon.cpp, DamageProfile.cpp, Entity.cpp
# DoStatusEffects, Ship.cpp). Every status level decays 1% per frame, so a
# point of a damage-over-time type does about 100 points in all, over ~5 s.
#	energy damage: energy removed at once; 50% blocked while shields are up.
#	ion damage: ionization level; drains that much energy per frame (about 100
#		energy per point in all); 50% blocked by shields. A ship whose
#		ionization exceeds its energy counts as ionized.
#	heat damage: heat added at once; 50% blocked by shields.
#	disruption: while the target has shields, the share of every hit that
#		the shields take is divided by (1 + disruption / 100), so the rest
#		goes to the hull (Shield Disruptor Turret: 0.24 per frame, a
#		standing level of 24). Needs shields; full strength while they last.
#	discharge: that many shields lost per frame (~100 per point in all);
#		only while the target has shields.
#	slowing: acceleration and turning divided by (1 + 0.05 x slowness);
#		50% blocked by shields.
#	scrambling: each weapon jams with chance 1 - 2^(-scrambling / 70);
#		50% blocked by shields.
#
# Flight ("magnetic", not "homing"): launched slowly (6), then a strong pull
# (acceleration 2.0 / 2.4 / 2.9) against heavy drag (.10 / .11 / .12) takes it
# to 95% of its top speed (20 / 21.8 / 24.2 px per frame, a Sidewinder's is 12)
# within about 22 frames; and because drag bleeds a tenth of its old velocity
# every frame, its course follows its nose within a few frames instead of
# drifting through wide arcs. It turns 14 / 17 / 20 degrees per frame (a
# Sidewinder 4, Swarm 5.35, Shard 8): a full reversal in 13 / 11 / 9 frames, a
# heading radius of about 80 / 74 / 69 px at top speed. "throttle control"
# cuts the pull while it swings round, then it snaps back on. "tracking" .94
# / .97 / 1 (the generic, jam-proof kind: neither radar nor optical jamming nor
# a cold hull fools it; at .94 a lock is lost on about 2.5% of the twice-a-
# second checks and usually regained). No "leading": it chases the target
# itself, as if pulled. Missile strength 20 / 24 / 28 (Sidewinder 18, EMP
# Torpedo 80, nuke 200): a Heavy Anti-Missile Turret (8) stops about one in
# six per shot, the Warden Warder (14) one in three, Glimmer Mk III (45) four
# in five. Straight-line reach 2,670 / 3,040 / 3,490 px in its lifetime
# (140 / 145 / 150 frames); "range override" 2,300 / 2,600 / 3,000 so the AI
# fires from where it actually connects.
#
# References (per shot / per second at the listed reload; space = outfit space):
#	weapon (ammo)                  space reload  energy    ion    heat  disrupt  disch  slow  scramble  shield/hull  missile str
#	Ka'het Nullifier (gun)            97    350  3200/549 220/38  -       -        -      -     10/1.7    120/40        -
#	EMP Torpedo Bay (Remnant)         18    330   -       48/8.7  -       -        -      -     48/8.7    700/100       80
#	Ka'het EMP Deployer               26    180   -       48/16   -       -        -      -     48/16     700/100       80
#	Korath Detainer (gun)             76     35   -       -       -       -        -     40/69   -        320/240        -
#	Shield Disruptor Turret           35      1   -       -       -     .24/14     -      -      -        3.8/.5         -
#	Plasma Turret                     60      9   -       -     425/2833  -        -      -      -        63/25          -
#	Ion Cannon (human)                47     60   -        6/6    -       -        -      -      6/6      168/60         -
#	Nuclear Missile (the ceiling)     10    400   -       -       -       -        -      -      -       9000/7000      200
#	Lamprey Mk I                      20     80  1800/1350 24/18 1000/750 50/38   4/3   16/12   12/9      30/15        20
#	Lamprey Mk II                     20     65  2600/2400 36/33 1500/1385 75/69  6/5.5 24/22   18/17     40/20        24
#	Lamprey Mk III                    20     50  3800/4560 54/65 2200/2640 110/132 9/11 36/43   26/31     50/25        28
#
# Energy actually drained per Lamprey through a target's shields (half the
